# 🚀 AI Blog Writer (FREE Local AI)

A modern AI-powered blog generator built with Python and Flask that runs 100% locally using Ollama (no API costs).

## ✨ Features
- Generate blogs instantly
- Works offline
- FREE forever (no OpenAI charges)
- Modern UI
- Fast local LLM
- Flask backend

## 🛠 Tech Stack
- Python
- Flask
- Ollama
- HTML/CSS
